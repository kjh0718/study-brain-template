# Clusters

관련 개념과 노트를 주제로 묶는 MOC 형태의 탐색 지도다. 지식이 아니라 **지도**다.

## 여기 두는 것

- 주제당 CLU 노트 하나
- 포함 기준, 구성원 링크, 학습 순서
- [`_topics.md`](_topics.md) — `topics` 값의 통제 어휘표

## 여기 두지 않는 것

- 새로운 개념 설명. Cluster를 지워도 지식은 남아야 한다
- 구성원이 하나뿐인 Cluster. 둘 이상일 때 만든다
- topic이 생겼다는 이유만으로 자동 생성한 Cluster
