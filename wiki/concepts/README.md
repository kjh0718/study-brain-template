# Concepts

특정 과목에 종속되지 않고 재사용되는 장기 개념을 담는다.

## 여기 두는 것

- 개념당 CON 노트 하나
- 정의, 직관, 적용 조건, 흔한 오해, 근거

## 여기 두지 않는 것

- 과목별로 복제한 같은 개념. 여러 과목이 같은 CON을 가리킨다
- 한 번만 등장한 용어. 근거 노트 본문에 후보로 남긴다
- 특정 수업 회차의 설명 → `study/lectures/`
