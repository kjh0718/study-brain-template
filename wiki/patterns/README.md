# Patterns

여러 자료에서 반복 확인된 패턴을 담는다. **Core Type이 아니다.**

## 여기 두는 것

- 서로 독립적인 근거가 둘 이상 쌓인 관찰
- 근거 목록(ID와 원본 위치), 반례를 확인한 범위와 결과, 한계, 적용 범위, 표본 수

## 여기 두지 않는 것

- 근거가 하나뿐인 관찰
- 학습 노트 frontmatter. 여기는 규격 검사 대상이 아니다
- 반례가 존재하지 않는다는 서술. 확인할 수 없다
- 기출 한 회차만으로 세운 출제 예측

## 규격

없다. 새 type이나 prefix를 만들지 않는다.
