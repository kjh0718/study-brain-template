## 정의

물체의 질량과 속도의 곱으로 정의되는 벡터량. p = mv.

## 직관

같은 속도라도 무거운 물체를 멈추기 어렵다는 사실의 정량화다.

## 공식 / 적용 조건

p = mv. 외력의 합이 0인 계에서 전체 운동량이 보존된다.

## 예제

탄성·비탄성 충돌 문제. LEC-20260908-01 참조.

## 흔한 오해

비탄성 충돌에서 운동량도 보존되지 않는다고 생각하기 쉽다. 보존되지 않는 것은 운동에너지다.
