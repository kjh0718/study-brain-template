## 정의

힘을 작용 시간에 대해 적분한 벡터량. J = ∫F dt.

## 직관

같은 힘이라도 오래 작용하면 운동 상태가 더 많이 바뀐다.

## 공식 / 적용 조건

J = ∫F dt = Δp (충격량-운동량 정리)
