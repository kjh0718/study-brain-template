# Reviews

복습 회차와 그때 관찰된 학습 상태를 기록한다. 지식이 아니라 **학습 상태**의 기록이다.

## 여기 두는 것

- 회차당 REV 노트 하나
- 복습 대상, 문항, 사용자 응답, 오개념, 다음 행동

## 여기 두지 않는 것

- 개념 설명 자체 → `wiki/concepts/`
- 응답 없이 추정한 점수나 이해도
- 문항만 만들고 완료 처리한 회차
