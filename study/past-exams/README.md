# Past Exams

기출·족보의 문항별 분석 결과를 담는다.

## 여기 두는 것

- 시험 회차당 PEX 노트 하나
- 문항별 개념·유형·난이도, 정답의 출처 구분, 표본 수

## 여기 두지 않는 것

- 기출 원본 → `raw/past-exams/`
- 현재 학기 시험 정보 → `study/exams/`
- 기출에 적힌 일정을 이번 학기 운영 사실로 옮긴 것
