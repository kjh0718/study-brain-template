# Questions

이해하지 못한 내용, 확인이 필요한 사실, 교수에게 물어볼 사항을 관리한다.

## 여기 두는 것

- 질문당 QST 노트 하나
- 질문, 발생 맥락, 답변 후보, 해결 근거

## 여기 두지 않는 것

- 복습 문항. 그것은 REV 본문에 둔다
- 사용자가 쓴 원래 문장. 보호 영역의 문장은 옮기지 않고 그 자리에 둔다
