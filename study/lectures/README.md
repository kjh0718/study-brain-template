# Lectures

실제 수업 세션 하나를 구조화한 노트다.

## 여기 두는 것

- 세션당 LEC 노트 하나
- 요약, 핵심 내용, 교수님 강조, 개념·질문·자료 연결

## 여기 두지 않는 것

- 전사 원문 → `raw/transcripts/`
- 자료 자체의 분석 → `study/resources/`
- 재사용 가능한 개념 설명 → `wiki/concepts/`
