# Exams

**현재** 수강 중인 과목의 시험 정보를 관리한다.

## 여기 두는 것

- 시험당 EXM 노트 하나
- 일정, 교수가 공지한 확정 범위, 교수의 시험 언급

## 여기 두지 않는 것

- 과거 기출 → `study/past-exams/`
- 수업마다 새로 만든 EXM. 기존 노트에 근거를 누적한다
- 족보 빈도나 AI 추정을 확정 범위로 적은 내용
