# Inbox

아직 분류하거나 처리하지 못한 입력의 임시 보관소다. 여기 있는 파일은 아직 원본으로 확정된 것이 아니다.

## 여기 두는 것

- 종류나 소속 과목을 확정하지 못한 입력
- 처리 도중 보류된 항목의 메모

## 여기 두지 않는 것

- 종류와 과목이 확정된 원본 → `raw/`의 해당 폴더
- 구조화 노트 → `study/`, `wiki/`
- 장기 보관물. 여기는 임시 영역이다

## 규격

해당 없음.

## 관련 워크플로

확정되면 해당 ingestion 레이어가 처리한다. 확정하지 못하면 그대로 두고 무엇을 확인해야 하는지 사용자에게 알린다.

추측으로 과목을 배정하지 않는다.
