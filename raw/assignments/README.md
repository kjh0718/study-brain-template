# Raw Assignments

과제 원문과 과제지의 **원본**을 보존한다.

## 여기 두는 것

- 과제 명세서, 과제지, 제출 요건 원문

## 여기 두지 않는 것

- 과제 진행 상태와 마감 관리 → `study/assignments/`
- 제출한 결과물. 이 저장소가 아니라 실제 제출처에 둔다

## 규격

해당 없음. `raw/`의 원본은 학습 노트가 아니므로 frontmatter 규격을 강제하지 않는다. 원본을 가리키는 구조화 노트가 규격을 갖는다.

## 관련 워크플로

[L5 Fact & conflict reconciliation](../../_system/workflows/l5-fact-conflict-reconciliation.md)

원본을 수정·요약·교정·삭제하지 않는다. 세부 규칙은 [`SECOND-BRAIN.md`](../../SECOND-BRAIN.md)의 저장소 구조와 데이터 흐름 절에 있다.
