# Raw Past Exams

기출·족보의 **원본** 또는 복원본을 보존한다.

## 여기 두는 것

- 과거 시험지 원본, 학생 복원본, 함께 받은 정답·해설

## 여기 두지 않는 것

- 문항별 분석 결과 → `study/past-exams/`
- 현재 학기 시험 정보 → `study/exams/`
- 일반 수업 자료 → `raw/resources/`

## 규격

해당 없음. `raw/`의 원본은 학습 노트가 아니므로 frontmatter 규격을 강제하지 않는다. 원본을 가리키는 구조화 노트가 규격을 갖는다.

## 관련 워크플로

[L3 Past-exam ingestion](../../_system/workflows/l3-past-exam-ingestion.md)

원본을 수정·요약·교정·삭제하지 않는다. 세부 규칙은 [`SECOND-BRAIN.md`](../../SECOND-BRAIN.md)의 저장소 구조와 데이터 흐름 절에 있다.
