# Raw Documents

다른 `raw/` 분류에 속하지 않는 학습 관련 **원본** 문서를 보존한다.

## 여기 두는 것

- 위 다섯 분류 어디에도 맞지 않는 원본 자료

## 여기 두지 않는 것

- 분류가 정해지면 해당 폴더로 옮긴다. 여기 오래 남겨 두지 않는다
- 아직 무엇인지 모르는 입력 → `inbox/`

## 규격

해당 없음. `raw/`의 원본은 학습 노트가 아니므로 frontmatter 규격을 강제하지 않는다. 원본을 가리키는 구조화 노트가 규격을 갖는다.

## 관련 워크플로

입력의 성격이 정해진 뒤 해당 레이어가 처리한다.

원본을 수정·요약·교정·삭제하지 않는다. 세부 규칙은 [`SECOND-BRAIN.md`](../../SECOND-BRAIN.md)의 저장소 구조와 데이터 흐름 절에 있다.
