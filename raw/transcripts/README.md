# Raw Transcripts

수업 전사본의 **원본**을 그대로 보존한다. 이후 어떤 정리가 잘못돼도 여기서 다시 확인할 수 있어야 한다.

## 여기 두는 것

- 수업 전체 전사본 원문
- 같은 수업이 여러 파일로 나뉜 경우 그 전부
- 전사 도구가 붙인 타임스탬프

## 여기 두지 않는 것

- 요약본이나 정리본 → `study/lectures/`
- AI가 다시 쓴 교정본. 필요하면 원본을 남기고 별도 파일로 만든다
- 강의 자료나 기출 → `raw/resources/`, `raw/past-exams/`

## 규격

해당 없음. `raw/`의 원본은 학습 노트가 아니므로 frontmatter 규격을 강제하지 않는다. 원본을 가리키는 구조화 노트가 규격을 갖는다.

## 관련 워크플로
