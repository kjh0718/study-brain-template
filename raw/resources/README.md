# Raw Resources

PPT, PDF, 교재, 프린트 등 학습 자료의 **원본**을 보존한다.

## 여기 두는 것

- 교수 배포 자료, 교재 스캔, 프린트, 논문 등의 원본 파일

## 여기 두지 않는 것

- 구조화한 자료 노트 → `study/resources/`
- 외부 URL만 있는 자료. 내려받지 않고 자료 노트의 `source`에 URL을 적는다
- 과거 시험지 → `raw/past-exams/`

## 규격

해당 없음. `raw/`의 원본은 학습 노트가 아니므로 frontmatter 규격을 강제하지 않는다. 원본을 가리키는 구조화 노트가 규격을 갖는다.

## 관련 워크플로

[L2 Resource ingestion](../../_system/workflows/l2-resource-ingestion.md)

원본을 수정·요약·교정·삭제하지 않는다. 세부 규칙은 [`SECOND-BRAIN.md`](../../SECOND-BRAIN.md)의 저장소 구조와 데이터 흐름 절에 있다.
